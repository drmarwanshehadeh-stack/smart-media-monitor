# Smart Media Monitor

نموذج تجريبي مجاني لبناء منظومة رصد إعلامي باستخدام FreshRSS كمجمّع للمصادر، مع تجهيز البيانات لاحقاً للتحليل داخل ChatGPT أو أدوات تحليل أخرى.

## الهدف

تجميع مصادر RSS/Atom في مكان واحد، تحديثها تلقائياً، تنظيمها موضوعياً، ثم تصدير النتائج للتحليل: إزالة التكرار، تصنيف الموضوعات، استخراج الكيانات، رصد الاتجاهات والسرديات، وإعداد موجز يومي أو أسبوعي.

## التشغيل السريع

1. ثبّت Docker Desktop أو Docker Engine مع Docker Compose.
2. انسخ `.env.example` إلى `.env` وعدّل القيم عند الحاجة.
3. شغّل:

```bash
docker compose up -d
```

4. افتح `http://localhost:8080` وأكمل إعداد FreshRSS من الواجهة.
5. أضف المصادر يدوياً أو استورد ملف OPML من مجلد `feeds/`.

## البنية

- `docker-compose.yml`: تشغيل FreshRSS محلياً.
- `.env.example`: إعدادات المنطقة الزمنية ودورية التحديث.
- `feeds/seed-feeds.opml`: قالب أولي لمصادر الرصد.
- `docs/monitoring-taxonomy.md`: تصنيف مقترح للرصد الإعلامي.
- `docs/workflow.md`: سير العمل من المصدر إلى التقرير.
- `scripts/normalize_export.py`: تجهيز ملف CSV مُصدَّر للتحليل وإزالة التكرار البسيط.
- `data/`: للبيانات المحلية، غير مخصصة للنشر.
- `exports/`: لمخرجات التحليل.

## الخصوصية

لا تضع كلمات مرور FreshRSS أو مفاتيح API داخل المستودع. استخدم `.env` محلياً فقط. الملف `.gitignore` يستبعد `.env` ومجلدات البيانات المحلية.
