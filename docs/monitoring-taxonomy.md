# تصنيف الرصد الإعلامي المقترح

## 1. الأردن
السياسة، الحكومة والبرلمان، الأمن والدفاع، الاقتصاد، الإعلام وحرية الصحافة، التشريعات الرقمية، المجتمع.

## 2. الشرق الأوسط
فلسطين وإسرائيل، لبنان، سوريا، العراق، إيران، الخليج، اليمن، تركيا.

## 3. الأمن والجماعات المسلحة
داعش، القاعدة، الجماعات المحلية، الإرهاب ومكافحته، النزاعات المسلحة، الأمن الإقليمي.

## 4. الإعلام والذكاء الاصطناعي
الذكاء الاصطناعي في غرف الأخبار، التنظيم والحوكمة، التضليل والتحقق، منصات التواصل، اقتصاد الإعلام.

## 5. المؤسسات ومراكز الأبحاث
الأمم المتحدة، المؤسسات الإنسانية، مراكز التفكير، الجامعات، التقارير الدولية.

## حقول التحليل المقترحة
المصدر، التاريخ، العنوان، الرابط، الدولة/المنطقة، الموضوع، الفاعلون الرئيسيون، نوع المادة، النبرة، درجة الأهمية، كلمات مفتاحية، ملخص، ملاحظات تحقق.
