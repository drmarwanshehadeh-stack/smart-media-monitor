# سير العمل

مصادر RSS/Atom → FreshRSS → تصنيف وفلاتر → تصدير CSV/OPML → تنظيف وإزالة التكرار → تحليل بالذكاء الاصطناعي → موجز يومي/أسبوعي → تقدير اتجاهات وسرديات.

## المرحلة التجريبية

ابدأ بعدد محدود من المصادر عالية الموثوقية. اختبر جودة التحديث، اكتمال العنوان والرابط، نسبة التكرار، ودقة التصنيف قبل توسيع قاعدة المصادر.

## المرحلة التالية

بعد نجاح التجربة يمكن إضافة طبقة أتمتة تستخرج المواد الجديدة دورياً وتدفعها إلى قاعدة بيانات أو ملف منظم للتحليل المتقدم.
