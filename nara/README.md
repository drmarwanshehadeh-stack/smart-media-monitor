# NARA — Al-Naba Analytical Research Assistant

وحدة بحثية تجريبية لتحليل أعداد صحيفة «النبأ» زمنياً وإحصائياً وخطابياً، مع التعامل مع الأرقام والوقائع المنشورة بوصفها **ادعاءات صادرة عن مصدر دعائي أحادي** ما لم يتم التحقق منها من مصادر مستقلة.

## المخرجات المستهدفة

- تقرير أسبوعي لكل عدد.
- تجميع شهري مع إزالة التكرار.
- تحليل ربع سنوي للاتجاهات.
- تقرير سنوي للمقارنة الزمنية والجغرافية.
- قاعدة بيانات للأحداث المعلنة.
- قاعدة بيانات مستقلة للافتتاحيات والخطاب الأيديولوجي.
- رسوم وخرائط ومؤشرات زمنية.
- طبقة تحقق اختيارية تقارن الادعاءات بمصادر مستقلة.

## قاعدة منهجية ثابتة

لا تُعامل بيانات الصحيفة على أنها حصيلة مؤكدة. كل رقم يُوسم مبدئياً `claimed`. ويمكن ترقيته لاحقاً إلى `corroborated` أو `verified` إذا توفر تحقق مستقل كافٍ.

## الهيكل

- `schema/` مخططات البيانات.
- `data/` بيانات التجربة الأولية.
- `docs/` المنهجية وقواعد العد ومنع التكرار.
- `scripts/` أدوات الاستخراج والتجميع والتحقق لاحقاً.

## العينة التجريبية

الأعداد 558 و559 و560، مع استخدام التقرير اليدوي لشهر أيار/مايو 2026 كمرجع مقارن لتصميم المخرجات وقواعد التجميع.
